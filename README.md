# 鹿屿の博客

这是 luyvzz 的个人网页博客，部署在 GitHub Pages。

访问地址：<https://luyvzz.github.io/>

## 内容定位

- 个人资料
- 具身智能和 AI 学习记录
- 嵌入式与机器人视觉笔记
- 开源项目展示
- 个人随笔

## 视觉方向

网站采用极客控制台风格，主色使用青绿色和琥珀色，头像来自 `assets/images/avatar.jpg`，网页展示版本为 `assets/images/avatar-cyber.png`。
