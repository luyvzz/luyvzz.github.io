关于我

你好，我是 luyvzz，一名正在搭建个人开源生态的大学生开发者。

我目前关注 AI、嵌入式和机器人视觉。这个博客会放一些个人资料，也会记录项目从想法到能跑起来的过程。很多东西一开始都不完整，但我想把它们整理成可以被别人看懂的样子。

这个站点和 GitHub 主页一起组成我的公开入口。面试官可以从这里看到我做过什么，开发者可以从这里找到项目背景，我自己也可以回头看每一次折腾留下了什么。
